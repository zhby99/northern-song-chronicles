# 恢复《北宋立志传》项目上下文 (`/resume-context`)

当用户输入 `/resume-context` 或要求接手项目、查看当前进度时，请按以下步骤执行：

## 执行步骤

1. **并行读取核心上下文文档**：
   - `AGENTS.md`（全局工程守则与时空锚点）
   - `docs/HANDOFF_CONTEXT.md`（跨分支演进历史与技术避坑备忘）
   - `docs/ROADMAP_AND_TODO.md`（里程碑完成度与 `[ ]` 待办任务列表）
2. **检查当前工作区状态**：
   - 在项目根目录运行 `git status` 与 `git log -n 5 --oneline`，确认是否有未提交改动以及最近完成的里程碑。
3. **向用户输出简明交接简报**：
   - 当前所处阶段（例如：M0 已完成，M1 进行到哪一步）。
   - 最近一次提交与本地工作区状态。
   - 推荐接下来立即推进的 1~2 个具体子任务（对照 `docs/ROADMAP_AND_TODO.md`），询问用户是否直接开始实施。
