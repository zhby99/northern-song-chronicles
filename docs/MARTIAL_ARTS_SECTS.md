## 一、 皇祐武林门派金字塔总纲与阶梯晋升机制

### 1.1 为什么采用“三十门派三级金字塔”？
在公元 1050 年的北宋江湖中，初出茅庐的白身少年若无名宿引荐、根骨奇佳或深厚十艺修养，往往难以一步登天踏入 **少林藏经阁**、**无量山琅嬛玉洞** 或 **太湖燕子坞**。为此，《北宋立志传》构建了真实鲜活的 **“三流市井把式 → 二流世家镖盟 → 一流泰山北斗”** 三级门派生态金字塔：

1. **【三流小派 · 市井武馆与地方帮会】（6 派 · `SECT-25..30`）**
   * **定位**：新手村与江湖第一站，扎根于 **济南府、杭州府、广州府、秦州府、成都府、潭州府** 六座南北繁华州府的演武馆、潮台、番港、边塞烽燧与苗市药堂。
   * **特点**：**零门槛或极低门槛随到随学**（仅需数两束脩银或完成一件跑腿小差事），传授 **凡品筑基至良品实用功夫**（如《查拳》《洪拳》《太祖长拳》《五禽养生功》《官制朴刀术》《燕子三抄水》），并提供 **码头扛包、巡港护商、采药熬膏、茶马趟子手、采蛊猎兽** 等稳定赚取第一桶纹银与行军干粮的新手差事。
   * **圆满出师礼**：将本馆主修武学练至第 5 重且门派贡献达标，馆主/帮主不仅允许少侠 **“圆满出师、另投高门”而不视为叛门**，还会亲笔修书一封 **《江湖举荐帖》**，大幅降低二流世家或邻近一流大派的拜师门槛！
2. **【二流门派 · 武林世家与行业水陆武盟】（6 派 · `SECT-16`、`SECT-18`、`SECT-21..24`）**
   * **定位**：初具名望的青年侠客历练中坚，坐落于 **扬州府、太行山、洛阳府、真定府、大名府、泉州府** 六大南北水陆山岳枢纽。
   * **特点**：掌门皆为 **一流上品至二流上品** 成名豪杰（如江淮漕帮厉沧海、太行绿林王重岳、洛阳金刀王元霸、常山枪派赵括苍、沧州八极卢铁山、闽海镇远总镖头林镇海），系统传授 **良品上品护体心法至地阶成名绝技**（如《鲸息水战诀》《太行罡气》《漕帮分水大枪》《洛阳金刀谱》《岳氏沥泉枪前谱》《八极崩拳》《六合大枪》《金钱镖》），并开启高收益的 **南北漕运押纲、太行劫富济贫、跨州重镖护送、宋辽榷场缉谍、远洋海舶护航** 等中阶历练。
   * **带艺投师与联姻举荐**：在二流门派立下大功后，可获掌门保举直入同阵营一流宗门深造（如 **江淮漕帮 → 洞庭铁掌帮 / 丐帮水路分舵**，**太行绿林盟 → 丐帮河北分舵 / 五台山清凉寺**，**洛阳金刀门 → 嵩山少林俗家 / 丐帮**，**常山枪派 / 沧州八极门 → 五台山 / 六扇门禁军**，**闽海镇远镖局 → 莆田南少林**）。
3. **【一流大派 · 名门正宗、隐世奇门与霸道强宗】（18 派 · `SECT-01..15`、`SECT-17`、`SECT-19..20`）**
   * **定位**：决定皇祐天下大势与华山/嵩山论剑格局的十八大顶级武林势力。
   * **特点**：坐拥独立名山秘境或王都总坛，由 **宗师乃至大宗师** 坐镇，执掌 **地阶镇派上乘与 37 门天阶旷世绝学**（《易筋经》《降龙十八掌》《北冥神功》《斗转星移》《真武太极剑意》《紫霞神功》等）。门规森严，择徒严苛（重经义、重侠义、看悟性颜值或需特殊机缘），一旦叛门将遭执法堂千里追捕。
