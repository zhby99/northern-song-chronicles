## 一、 全局审视：当前项目的四大长板与三大结构性张力

### 1. 已经立住的四大核心长板
* **鲜明且自洽的时空锚点（皇祐二年 · 1050 AD）**：朝堂名臣（范仲淹、欧阳修、包拯、狄青、少年三苏/王安石/司马光、毕昇/沈括/苏颂）与《天龙八部》前传黄金武林同处一炉，既有北宋市井庙堂的厚重考据，又有群侠并起的江湖张力。
* **干净的确定性数值底座**：先天三维（`根骨/悟性/颜值`，严禁入战中公式，专司修炼速率、破境与社交奇遇）+ 实战四维（`气血/身法/内力/抗性`）+ 十一大类 246 门武学 + 7 槽披挂兵武共鸣 + 同步盲选六择一心理博弈战斗，底层数学模型清晰稳定。
* **成熟的声明式长卷叙事管线**：`questEngine.ts` + `StorySceneModal.tsx` + `QuestTreeTab.tsx` 已经验证了 20~48 幕多分支、零内功开局友好、兼容多维十艺/天赋检定与插画演出的工业化叙事能力。
* **100% 落地的宋风视觉资产库**：43 座州府名山全景、268 座建筑内景、1,047 名 NPC 立绘/模板映射与 102 幅剧情 CG 全部就位，不再受缺图断链掣肘。

### 2. 当前面临的三大结构性张力（后续设计重点突破方向）
1. **常规门派版图的“临门两脚”**：
   * 全游戏共 **33 个武林门派 + `ORG-08` 大理皇室**（合计 34 个可交互武学势力）：
     * **三流武馆帮会（6 派，`SECT-25..30`）**：已 100% 跑通（束脩入门、晋升、举荐帖）。
     * **二流世家镖盟（6 派，`SECT-16, 18, 21, 22, 23, 24`）**：已 100% 跑通（含绿林纳投名状、八极门大名府奇案、常山枪派军饷与半年诛谍）。
     * **一流大派已开放（13 派）**：少林（`01`）、丐帮（`02`）、五台山清凉寺（`03`）、莆田南少林（`04`）、华山（`05`）、泰山（`06`）、峨眉（`07`）、真武道宗（`08`）、青城（`14`）、铁掌帮（`15`）、开封府/六扇门（`17`）、星宿派（`19`）、大宋禁军（`33`）。
     * **远期隐世/异族锁定池（`DLC_LOCKED_SECTS`，7 派）**：逍遥（`09`）、姑苏慕容（`10`）、桃花岛（`12`）、大理皇室（`ORG-08`）、西夏一品堂（`20`）、辽国暗桩（`31`）、吐蕃密宗（`32`）。
     * **唯一悬空缺口（2 派）**：**`SECT-11` 终南隐宗** 与 **`SECT-13` 蜀中唐门**。这两派并未归入 DLC 锁定池，且已在 `DAO_SWORD_SECT_IDS` 中接入了二月初一宗门大比与晋升规则，唯独缺少入门长卷。补齐这两块拼图，常规 26 门派即可实现 100% 闭环。
2. **“强剧情演出”与“自由沙盘涌现”的比重失衡**：
   * 当玩家处于某条 20 幕门派长卷或禁军战役中时，心流非常绵密；但一旦任务完结回到大地图，**日常跑图（目前路途随机事件仅 3 条纯文本）**、**1,047 名 NPC 的非任务社交** 以及 **成名后的中长期沙盘追求（如冲击天下武道榜、经营人脉网）** 略显单薄。
3. **前期紧平衡与中后期目标/经济出口断层**：
   * 前期 20 两束脩、每日 3 两异乡宿费、买干粮丹药很有生存紧迫感；但中后期手握数千两纹银后缺乏高价值消耗漏斗，同时各大正派 `minSectRank === 5` 的**镇派天阶上品神功**尚缺名正言顺的终局获取途径。

## 二、 近期演进三步走构想（通往“纯本地完整可玩版”）

### 第一步：收官常规门派入门版图（终南隐宗 & 蜀中唐门）

在设计这两条入门长卷时，可延续现有各派“零武学白身友好 + 同脉三流/二流带艺转投支持 + 鲜明地域文化质感”的成熟范式，并做出流派差异化：

* **`SECT-11` 终南隐宗（驻地：终南山）——清冷出尘的古墓寒玉与全真先声**
  * **时代风味锚点**：公元 1050 年重阳祖师尚未创全真教，终南隐宗承载的是唐宋隐逸剑仙遗脉与林朝瑶活死人墓寒玉清修一脉的合流前传。
  * **体验差异化**：区别于华山的“孤峰险棋”和真武的“太和道心”，终南隐宗可主打 **「红尘勘破 · 寒潭试心」**——例如自京兆府（长安）碑林或终南山麓古观起笔，围绕轻功身法潜行、水帘深潭屏息耐寒、断龙石畔残碑解谜展开；强调高身法、清心寡欲与剑掌轻灵之美。
* **`SECT-13` 蜀中唐门（驻地：成都府/唐家堡）——世家森严的机括暗器与医毒同源**
  * **流派补位价值**：当前已开 13 个一流门派涵盖禅宗、刀剑、拳掌、枪棍、毒功（星宿）与军伍公门，唯独缺少 **「机巧暗器 + 世家门阀」** 代表。
  * **体验差异化**：唐门不轻纳外姓，可设计为无门无派（或 **巴蜀百草药王门 `SECT-29`** 医徒凭医毒根基引荐）于成都府药市/茶肆卷入唐门外围暗器追缴风波，闯过竹海机括迷阵（算术/身法检定）与奇毒辨识考校（悟性/医理抉择），破例获授外姓执事弟子身份，填补暗器流派的一流宗门体验。

### 第二步：激活 1,047 人社交生态与《皇祐风云榜》（对应 `M3-2` / `M3-3`）

《太阁立志传》最迷人的地方在于“天下英雄皆可结交、请教、比肩”。围绕现有 1,047 人全量数据库，可从三个维度让群侠真正活起来：

#### 1. 文武分途的社交手段：【雅集论道 / 十艺唱和】
* **设计初衷**：`npcs.json` 中前 100 号人物全是宋仁宗朝的文坛领袖、名臣良相与科技巨匠（欧阳修、范仲淹、司马光、王安石、苏洵、苏轼、毕昇、沈括、苏颂、贾宪），玩家不可能靠“切磋打架”去刷欧阳修或毕昇的好感。
* **机制构想**：
  * 在 `NpcInteractionOverlay` 中新增 **【雅集论道】**（或按对方最高十艺动态显示为 *诗词唱和 / 手谈一局 / 经义问难 / 策论天下 / 算学考校 / 抚琴知音*）。
  * 每月可与同一名宿论道 1 次：根据双方对应十艺差值与主角【悟性/辩才/颜值】进行判定——大胜/投契不仅大幅提升好感度，还能反向获得该项十艺经验与名宿独白点评（甚至在十艺 ≥ 80 时触发名臣赠字画、举荐信或百工奇器）。
* **高阶赠礼解禁**：目前送礼面板仅限凡阶/良阶物品。建议允许向王公名宿、掌门宗师赠送**地阶/天阶非绑定典籍书画、名茶美酒与雅器奇珍**（保留任务关键道具锁），让玩家收集的皇祐百卷字画与博物奇珍拥有极高的社交战略价值。

#### 2. 高好感度的质变节点：【义结金兰 / 知己红颜 / 请教绝艺】
* 当 NPC 好感度从普通友善迈入 **`+80`（生死之交）** 乃至 **`+95`（莫逆知己）** 时，提供明确的玩法回报：
  * **义结金兰 / 知己盟誓**：限额结交数位生死弟兄或红颜知己，记录于主角生平卷宗；
  * **请教散传武学或十艺真传**：若对方并非严格秘传锁死的镇派绝学持有者（如散人名侠、朝堂武将、异域奇人），高好感 + 对应根骨/悟性达标时可获其指点成名招式或十艺突破；
  * **危机助拳与终局响应**：在后续英雄大会（武林盟主终局）或大型秘境闯关中，生死之交可出面助阵或替主角说项。

#### 3. 沙盘导航灯塔：《皇祐风云榜》与【故人结交录】
* **《皇祐风云榜》面板**：
  * **【天下武道百强榜】**：基于全库 1,047 名 NPC 与主角当前的实时有效四维、运使武学品阶重数及天阶特效权重，动态排出当世前 100 位高手。玩家能直观看到自己从“榜上无名”一路杀进“前五十 → 前十 → 问鼎榜首”的成长轨迹，点击榜上高手可查看其风闻驻地。
  * **【三十三门派威望榜】** 与 **【大宋十艺大宗师榜】**：展示各派综合实力消长（受大型剧情如太行剿匪、抗辽护关影响）及十艺魁首（如诗词欧阳修、算术贾宪、百工毕昇/苏颂），给文武双修玩家提供收集与超越的目标。
* **【故人结交录】（社交寻人痛点根治）**：
  * 1,047 人图鉴适合博物品鉴，但不适合日常找人。在【行囊枢机】中提供独立的“故人录”视图（筛选所有 `好感度 ≠ 0`、结义/师承、或当前有任务交集的 NPC），直接显示其**当前所在州府与最末层建筑**（兼容游历宗师动态位置），支持**一键规划官道行程**。

## 三、 核心系统深度打磨与玩法化学反应思考

### 思考 1：一流门派 Lv.4 / Lv.5 与「镇派天阶上品」的终局传承机制
* **问题本质**：在武侠世界观里，星宿派靠“弑师丁春秋”夺掌门之位非常贴合邪派逻辑；但少林、丐帮、华山、峨眉、真武等名门正派，玄慈、汪剑通、岳沧溟正值壮年，若让玩家在皇祐二年轻易取代他们当掌门既违背历史锚点，也会产生管理门派日常的违和感。然而 `MARTIAL_ARTS_COMPENDIUM` 中各派最顶级的**天阶上品镇派神功**要求 `minSectRank === 5`（掌门级权限）。
* **优雅解法——【护派大考 / 秘阁传薪（授首席护法 · 掌门信物）】**：
  * 为各一流正派设计通用的终极传承阶梯：当弟子晋至真传/长老、门派贡献充沛、掌门好感 ≥ 85、武道境界迈入【一流上品 / 宗师】后，可向掌门请命开启 **【镇派绝学大考】**（例如连破本门三大宿老联手护法大阵，或完成一件护持本门道统的宗师级委托）。
  * 考校通过后，授予 **「少掌门 / 首座护法衣钵信物」**（权限视同 Rank 5 传功许可），正式开放藏经阁顶层/秘洞的镇派天阶上品神功修习，既保全了原著宗师地位，又给了门派专精玩家最圆满的终局养成爽感。

### 思考 2：北宋皇祐经济烟火气与中后期银两漏斗（Economy Loop）
* **开源（让不同出身都有贴合身份的生财之道）**：
  * **镖行押镖与漕运护航**：在闽海镇远镖局、江淮漕帮或各大州府开放跨城押镖，收益随路途里程与险度浮动，途中可能遭遇绿林劫镖生死战——把大地图寻路、坐骑负重脚力与战斗无缝拧成一股绳。
  * **宋辽夏榷场特产行商**：北宋皇祐年间商业极盛（川蜀锦茶、两淮官盐、江南丝瓷、河东铁器、幽燕北马、党项青盐、大食香料）。无需做复杂的期货大盘，只需在十余座枢纽城市的市集/榷场提供 1~2 种地域特产的产地低买、异地高卖（限随身行囊格数或驼马负重），立刻就能还原《清明上河图》式的行商乐趣。
  * **文人润笔与医卜悬壶**：高【书/画/诗词】可在书肆临池卖字画；高医理/药道可在药铺坐堂义诊（兼赚纹银与侠义声望）。
* **节流 / 消耗漏斗（让中后期几千两纹银花得心甘情愿）**：
  * **大相国寺旬日鬼市 / 番舶珍宝拍卖**（注：现行版本已将大相国寺年度拍卖改为每年六月的【开封大集】定价出售；以下为远期构想）：每月初一、十五在汴京大相国寺或泉州番坊随机刷出高价古籍残卷、天山雪莲/九转灵药、名家真迹（高额送礼佳品）或良驹线索；
  * **名冶重铸与兵刃铭文淬炼**：在太原晋阳铁冶坊、杭州龙泉剑铺消耗重金与玄铁矿石，为心爱的良阶/地阶兵刃打磨开锋（小幅提升威力或激活额外共鸣词条）；
  * **置办雅集宴席**：在汴京樊楼、扬州二十四桥、江宁秦淮酒楼豪掷百金设宴，一次性邀集同城数位名宿名侠饮酒论交，群体提升好感度与江湖声名。

### 思考 3：让「十艺百工」产生全天候常驻收益
目前十艺已有完善的书院修习曲线与 80/90 级先天三维反哺，若再挂载一层轻量常驻被动效果，文武兼修的策略性会大幅跃升：

### 思考 4：战斗系统的微操博弈与体验减负（QoL）
1. **披挂与武学快捷预设（Loadout Presets）**：
   * 玩家平时赶路可能穿戴加移速的轻装、挂载待练级的低重武学；一旦突入高难剧情战或宗师切磋，逐槽更换 7 件装备 + 6 门武学较为繁琐。在【贰·披挂与武学】支持保存 **2~3 套命名方案（如「日常赶路」「主力决战」「奇门毒音」）** 一键切换，并在重要剧情开战选项旁标注战力预警，能极大提升流畅度。
2. **盲选回合的「守御回气」与「破绽博弈」**：
   * 同步盲选六择一的核心乐趣在于“猜对手这回合出大招还是防守”。可检查高消耗天阶武学连番交锋时的内力续航——让【守御架势】在减伤反震之外稳定回复一定比例内息，并对盲目抢攻的招式形成小幅破绽反制，避免战斗退化为单纯按最高面板招式互拍。
3. **长篇连战的「幕前临阵自动存档」**：
   * 在多轮生死连战（如护驾连战、太行三部曲决战）触发前，自动写入一个独立的临时检查点或自动槽提示，防止玩家因一招猜错战死后需要重跑长篇前置对话。

### 2. M3 确定性骨架如何优雅迎接 M4（LLM）与 M5（双终局）
* **M4 大模型“锦上添花而不越俎代庖”原则**：
  * 自由对话（心智引擎）与自由行动（司命 DM）绝不直接手改气血/银两/武学 ID，而是只输出受 JSON Schema 严格限幅的意图枚举（如 `favorDelta: [-5, +5]`, `shareRumorId`, `triggerSpar`, `unlockClueFlag`）。断网或未配 API Key 时，100% 无缝回退至 M3 的性格对白与雅集模板。
  * 月度《皇祐江湖风闻录》可直接读取 M3 的风云榜位次变动、门派威望消长与玩家近期事迹，生成各地酒楼说书人口中的鲜活评书。
* **M5 双终局的水到渠成**：
  * 一旦 M3 完成了 **【武道百强榜】** 与 **【门派威望 / 生死之交谱系】**，M5 的两大终局就有了坚实的量化触发器：
    1. **【天下第一 · 华山/嵩山绝顶论剑】**：只看纯武道硬实力——武道榜进入前五后开启绝顶论剑帖，连战当世绝顶大宗师（玄澄/鸠摩智/萧远山/慕容博/无崖子乃至扫地僧印证）。
    2. **【武林盟主 · 洛阳/雁门英雄大会】**：兼看武功、德望与人脉——武道榜前十 + 侠义声望达标 + 至少 8 大门派青眼相加 + 结义豪侠助阵，于塞外南侵大劫之际聚义执掌盟主令，最终生成宋代史传体《个人江湖列传》卷轴。

## 五、 工程健康度与架构演进备忘

1. **`useGameStore.ts` 模块化切片（Zustand Slices 重构预案）**：
   * 当前 `src/store/useGameStore.ts` 体量已超过 **8,100 行**。在后续大规模写入 M3 社交、风云榜与奇遇系统前，建议将其按业务域拆分为独立 Slice 文件（如 `navigationSlice.ts`、`cultivationLoadoutSlice.ts`、`combatSlice.ts`、`sectSlice.ts`、`questSlice.ts`、`socialRankingSlice.ts`），在根 Store 聚合导出。
   * **核心约束**：拆分仅改变代码组织结构，**保持对外 Hook 签名与 `SerializableGameState` 存档 Schema 完全不变**，做到零功能回归、高内聚易维护。
2. **文档与编译管线一致性**：
   * 每次完成大模块迭代后，顺手同步 [`ROADMAP_AND_TODO.md`](./ROADMAP_AND_TODO.md) 与 [`PROJECT_GUIDE.md`](../PROJECT_GUIDE.md) 中的统计口径（如门派开放数、任务总数、CG 覆盖率），确保跨会话交接时文档与代码零温差。
   * 涉及静态设定表（地区、建筑、武学、百兵、NPC）的新增或数值调整，始终坚持修改 `docs/*.md` 单一事实源并执行 `npm run build:db` 生成 JSON；每次提交前跑通 `npm run lint && npm run build`，守住单文件离线包（`build:artifact`）零裸路径与沙箱安全防线。
